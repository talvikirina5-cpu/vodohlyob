# Водохлёб

Мобильный wellness-трекер воды на React Native, Expo и TypeScript.

## Открыть приложение

Веб-версия: [talvikirina5-cpu.github.io/vodohlyob](https://talvikirina5-cpu.github.io/vodohlyob/)

## Возможности MVP

- персональный профиль и расчёт дневной нормы;
- быстрый и ручной ввод воды;
- анимированная объёмная бутылка;
- локальная история потребления;
- серии из семи выполненных дней;
- кристаллы и магазин дизайнов бутылок;
- редактирование дневной цели.

## Запуск

```bash
pnpm install
pnpm start
```

После запуска отсканируйте QR-код приложением Expo Go.

## Проверки

```bash
pnpm typecheck
pnpm test
```

Все пользовательские данные хранятся локально в AsyncStorage. Схема хранилища
имеет собственную версию и подготовлена к миграциям.
